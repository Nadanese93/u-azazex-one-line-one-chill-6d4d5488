A single sentence of horror, under 200 characters: a dead store's self-checkout knows the shopper by name. The program writes the line to `entry.txt`.

> The self-checkout thanked me by name, and I have never typed it in, because this store closed six years ago.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
